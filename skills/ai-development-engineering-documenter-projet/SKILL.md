# Documenter le projet

Lire `/home/johan/.codex/skills/references/documentation.md`, les conventions applicables et les décisions humaines. Identifier les sources et destinations documentaires concernées, sans dupliquer une référence existante.

Pendant l’implémentation, modifier la documentation dans sa destination prévue, dans le worktree de la demande, et inclure les changements dans le commit de la tâche. Préserver la structure des README et les traces historiques ; adapter les liens nécessaires. Signaler toute destination indéterminée ou décision manquante.

Vérifier le diff, la structure et les liens avec les contrôles adaptés, dans les limites des règles de tests lourds. Documenter résultats et limites, puis soumettre le contenu à la vérification humaine avec la tâche. Une vérification technique ne remplace pas la relecture humaine. Ce skill ne crée aucune autorisation Git supplémentaire.
