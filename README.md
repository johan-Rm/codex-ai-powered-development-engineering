# Codex AI-powered Development Engineering

Skills Codex pour les workflows AI-powered Development Engineering (AIDE).

## Organisation

- `skills/ai-development-engineering-*` : étapes des demandes et capacités réutilisables des workflows.
- `skills/references/` : documentation de référence partagée entre skills.

## Installation Codex

Si `~/.codex` contient déjà une configuration, comparer les fichiers du dépôt avant de les intégrer, sans écraser les données existantes. Copier les dossiers de skills dans `~/.codex/skills/` et les références partagées dans `~/.codex/skills/references/`.

Recharger l’extension Codex dans VS Code pour découvrir les skills dans une nouvelle session.

## Mise à jour

Vérifier l’état local et comparer les changements avant toute mise à jour. Ne pas écraser les fichiers personnels ou les modifications locales.
