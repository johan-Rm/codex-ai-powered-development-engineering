# Codex AI-powered Development Engineering

Prompts et skills Codex pour les workflows AI-powered Development Engineering (AIDE).

## Organisation

- `prompts/` : étapes des demandes de développement et de consolidation.
- `skills/ai-development-engineering-*` : capacités réutilisables des workflows.
- `skills/references/` : documentation de référence partagée entre skills.

## Installation Codex

Si `~/.codex` contient déjà une configuration, comparer les fichiers du dépôt avant de les intégrer, sans écraser les données existantes. Copier les prompts dans `~/.codex/prompts/`, les dossiers de skills dans `~/.codex/skills/` et les références partagées dans `~/.codex/skills/references/`.

Recharger l’extension Codex dans VS Code pour découvrir les prompts et skills. Les prompts personnalisés sont dépréciés par Codex ; leur disponibilité future n’est pas garantie.

## Mise à jour

Vérifier l’état local et comparer les changements avant toute mise à jour. Ne pas écraser les fichiers personnels ou les modifications locales.
